# 怕怕調音台（桌面版）

即時電音、電話音、答錄機音、EQ／壓縮／混響，並可錄音回放。
麥克風 → 處理 → 同時輸出到「耳機（監聽）」與「虛擬麥克風（直播）」。

## 一、第一次安裝（只做一次）

1. 安裝 **Python**（建議 3.12）：https://www.python.org/downloads/
   安裝畫面最下面一定要勾 **Add Python to PATH**。
2. 安裝 **VB-Cable**（虛擬音訊線）並重新開機。
3. 聲卡上的**硬體監聽關掉或調到最小**，並戴上耳機。

## 二、先試用（不打包）

雙擊 `run.bat`。第一次會自動安裝套件（需要網路），之後直接開啟程式。

## 三、打包成獨立 exe

雙擊 `build.bat`，完成後在 `dist\PaPaVoiceFx.exe`，複製到桌面即可，不用再裝 Python。

## 四、使用

1. 麥克風輸入選你的聲卡。
2. 監聽輸出選你的聲卡（耳機聽的）。
3. 直播輸出選 `CABLE Input`。
4. 按「▶ 開始」。
5. 雷電模擬器的麥克風來源選 `CABLE Output`；沒有這個選項時，把 `CABLE Output` 設為 Windows 的預設錄音裝置。

### ★ 聲卡變音（重現舊聲卡的效果）
按「★ 聲卡變音」預設即可。這組設定是比對你的原聲和「說話二」量出來的：
- 音高升 +1.5 個半音（聲線跟著一起變亮）
- 中低頻（約 125～320 Hz）降 6 dB、3.2 kHz 附近凹 5 dB
- 不加壓縮、不加混響（說話二裡的輕微混響已刻意排除）

想微調可以拉「整體升降調」（0.1 為單位），再用錄音功能和舊錄音對比。

### 降低延遲
- 區塊大小選 128（再小可能會爆音）。
- 勾「低延遲電音」。
- 聲卡的 Windows 聲音內容 → 進階，輸入與輸出都設成 `24 位元，48000 Hz`，並關閉音訊增強。
- 可試「WASAPI 獨佔模式」：延遲最低，但那張聲卡同時不能給其他程式用；失敗時會自動退回一般模式。
- 畫面右側會顯示預估延遲與「緩衝不足次數」。次數一直增加代表會爆音，請把區塊調大。

### 錄音
- 「● 錄音」同時錄下**處理後**與**原聲**兩軌（最長 5 分鐘）。
- 錄完按「▶ 聽處理後」或「▶ 聽原聲」，在耳機對比；回放時直播輸出不受影響。
- 「💾 存成 WAV」會存到「文件\PaPaVoiceFx\recordings」，並自動開啟資料夾。

### 全域快捷鍵（不用切視窗）
`Ctrl+Alt+` ＋ `1` 說話　`2` 唱歌　`3` 電音歌　`4` 電話音　`5` 答錄機音　`6` 聲卡變音
`E` 電音開關　`P` 電話音開關　`M` 答錄機音開關　`R` 錄音開關

### 資料位置
- 設定：`%APPDATA%\PaPaVoiceFx\settings.json`
- 錯誤紀錄：`%APPDATA%\PaPaVoiceFx\error.log`（程式有問題時請把這個檔案內容給我）

## 開發者用

- `dsp.py`　處理核心（numpy／scipy）
- `engine.py`　聲音輸入輸出與錄音（sounddevice）
- `app.py`　介面（tkinter）
- `python test_dsp.py`、`python test_engine.py`　離線測試（不需要聲卡）
