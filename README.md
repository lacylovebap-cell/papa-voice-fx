# 怕怕調音台

## 第一次使用
1. 安裝 VB-Cable 並重新開機（直播用的虛擬麥克風）。
2. 聲卡上的硬體監聽關掉，戴上耳機。
3. 打開 `PaPaVoiceFx.exe`。

## 畫面說明
- **▶ 開始**：開始處理聲音。
- **🔒 聲卡變音**：預設一直開著，不管按什麼效果都會疊在上面，直播不會出現原音。只有按這顆才會關。
- **聲音管道**：麥克風／耳機／直播／伴奏各一行，可以選裝置、調音量，右邊有聲音就會跳動。
  程式會自動選：麥克風＝Tenlamp、耳機＝Tenlamp、直播＝CABLE Input、伴奏＝Realtek Digital Output。
- **效果**：說話／唱歌／電音／電話／答錄機，再按一次就關掉。
  修音和電音都會自動跟著你唱的歌判斷調，不用選調。
  - 🎤 自然修音：只把走音拉回來，保留顫音和滑音（Auto-Tune「自然流行」設定）。
  - ⚡ 電音：可選電音風格：流行網感（微微電音）／抒情／現代流行／說唱（最電）。
  - 修音和電音都已經包含人聲修飾的音色，不用另外調。
- **🌫 混響、🦷 去齒音**：在效果下面各一條拉桿，調一次就固定，切換任何效果都會沿用。
- **錄音**：錄下直播出去的聲音，按「聽錄音」在耳機聽，「存檔」存成 WAV。

## 伴奏怎麼接（只要設定一次）
1. Windows 搜尋「音量混音程式」並打開。
2. 把「Google Chrome」的輸出裝置改成「Realtek Digital Output」。
3. 調音台的「伴奏」選「Realtek Digital Output」，按開始，在 Chrome 播歌。
伴奏不會被變音，會跟人聲一起送到耳機和直播，直播裡會自動對齊。

## 快捷鍵（不用切視窗）
Ctrl+Alt+ `1` 說話 `2` 唱歌 `3` 電音 `4` 電話 `5` 答錄機 `6` 聲卡變音 `B` 伴奏 `R` 錄音

## 有問題時
- 聲音破、很吵：畫面上方出現紅字「麥克風太大聲」時，把聲卡上的麥克風旋鈕轉小。輸出已有限制器，不會再硬削波。
- 爆音：程式會自動加大緩衝；也可以到進階設定確認「超低延遲」沒有勾。
- 雜音：確認聲卡上的硬體監聽已關掉（不然耳機會同時聽到原音和處理後的聲音）。
- 錯誤紀錄：`%APPDATA%\PaPaVoiceFx\error.log`，把內容給 Claude。
