# PAPA 調音台

## 第一次使用
1. 安裝 VB-Cable 並重新開機（直播用的虛擬麥克風）。
2. 聲卡上的硬體監聽關掉，戴上耳機。
3. 打開 `PaPaVoiceFx.exe`。

## 畫面說明
- **▶ 開始**：開始處理聲音。
- **🎭 變聲**：升 1.5 半音並調整音色（重現怕怕舊聲卡的變聲）。一般歌手預設關閉、用原聲，想用再按。
  - **專屬模式**（進階設定裡勾選，怕怕專用）：開機自動開變聲、任何效果都疊在上面、關掉前會再確認，直播不會不小心出現原音。
- **聲音管道**：麥克風／耳機／直播／伴奏各一行，可以選裝置、調音量，右邊有聲音就會跳動。
  程式會自動選：麥克風＝Tenlamp、耳機＝Tenlamp、直播＝CABLE Input、伴奏＝Realtek Digital Output。
- **效果**：說話／唱歌／電音／電話／答錄機，再按一次就關掉。
  修音和電音都會自動跟著你唱的歌判斷調，不用選調。
  - 🎤 自然修音：只把走音拉回來，保留顫音和滑音（Auto-Tune「自然流行」設定）。
  - ⚡ 電音：先按「⚡ 電音」才能選風格，由弱到強：微電／電音／強電／爆電（最強）。
  - 修音和電音都已經包含人聲修飾的音色，不用另外調。
  - 每個效果按鈕上方都寫著它的快捷鍵（例如機器人＝Ctrl+Alt+7）。
- 所有效果都不自帶混響或回音，只有自己把混響拉上去才會有。
- **✋ 無效果**：完全沒有混響，只有變聲（專屬模式開著就一定是變聲後的聲音）＋人聲質感。
  無效果的人聲質感是自己的一組；說話、修音、電音等效果共用另一組。切來切去各自記住。
- **🔇 降噪**：沒出聲時把細細沙沙的小雜音壓掉（0＝不處理，越右壓越多）；出聲時不影響、不增加延遲，所有效果共用。
- **⚡ 一鍵**（混響和人聲質感中間的小按鈕）：CD、流行、甜歌、抒情、悲傷、古風、說唱、搖滾、爵士、清唱。按一下換成那種歌的混響 A／B／C＋人聲質感（效果、變聲不動）；「↶ 復原」一次退一步。
- **⬆ 一鍵更新**：右上角「檢查更新」。打開時也會自動檢查，有新版按鈕會變黃色；按下去會下載新版、自動關掉換好再打開，設定都保留（直播中建議下播再更新）。
- 滑鼠滾輪只會捲動頁面，不會改到下拉選單（以前滾過去會不小心換掉裝置）。
- **🌫 混響 A／B／C**：三層獨立混響，各自選類型（經典、房間、人聲板、大廳、教堂）和深度，所有效果共用：
  拉 10 切到哪個效果都是 10，拉 0 就全部沒有。⚙ 可以細調殘響長度、明亮度、預延遲、立體寬度、低頻清除。
- **🦷 去齒音**：只在嘶、ㄘ、ㄙ 這類刺耳齒音出現時才壓，所有效果共用。
- **錄音**：每錄一段就暫存在清單裡（最多 30 段），選一段可以聽、存檔或刪除，不用每段都存。

## 🎛 混音台（第二頁，Studio One 風格）
- 通道：麥克風、人聲、伴奏、混響 A／B／C、耳機，每條都有直立推桿和音量表。
- 人聲通道的插入效果（變聲、效果、EQ／壓縮、去齒音）點下去，右邊就出現旋鈕可以細調：
  上下拖曳＝調整、按住 Shift＝更細、滑鼠滾輪＝一格一格、雙擊＝恢復預設。
- 每個效果的細調各自記住，切到別的效果再切回來還在；「↺ 恢復這個效果的預設」可以回到原本。
- 自然修音／電音有 Auto-Tune 的旋鈕：修正速度、Flex-Tune、Humanize、自然顫音，
  還能一鍵套用參考預設（自然修音 80/30/80、通用型 50/25/50、流行網感 35/25/80、R&B 絲滑 20/20/20、說唱電感 10/5/10、電鰻 0/0/0）。
- 變聲的專屬參數（升 1.5 半音、350 Hz −6 dB、3.2 kHz −5 dB）固定不能調，不會被任何細調改到。

## 💾 我的設定（自己取名字的存檔）
- 最上面一排。按「＋ 存目前設定」取名字（例如：怕怕專屬一、怕怕說唱），會存目前的效果、所有細調、混響、去齒音。
- 之後按那個名字＝一鍵切換；前 8 組也可以用快捷鍵 Ctrl+Alt+F1～F8。右鍵可以覆蓋、改名、刪除。
- 不會動到變聲開關和各管道音量。

## ⏱ 伴奏對齊
直播裡人聲和伴奏沒貼齊時：錄一段 → 播放 → 一邊聽一邊拉「伴奏對齊」（播放中會即時改變）。
人聲比伴奏慢（拖拍）＝往右，人聲比伴奏快（搶拍）＝往左。只影響直播和錄音，不影響耳機。

## 伴奏怎麼接（只要設定一次）
1. Windows 搜尋「音量混音程式」並打開。
2. 把「Google Chrome」的輸出裝置改成「Realtek Digital Output」。
3. 調音台的「伴奏」選「Realtek Digital Output」，按開始，在 Chrome 播歌。
伴奏不會被變音，會跟人聲一起送到耳機和直播，直播裡會自動對齊。

收音＋耳機在同一條線、處理在獨立的高優先權執行緒，不會被畫面卡住。

## 有問題時
- 聲音破、很吵：畫面上方出現紅字「麥克風太大聲」時，把聲卡上的麥克風旋鈕轉小。輸出已有限制器，不會再硬削波。
- 爆音：程式會自動加大緩衝；也可以到進階設定確認「超低延遲」沒有勾。
- 唱歌當下（耳機）、回放、存檔三個永遠一樣大：要一起大聲就拉「🔊 總音量」；「耳機」那條只能調小。自己聽太小聲請調 Windows 音量或耳機旋鈕。
- 麥克風和耳機在不同聲卡（例：麥克風 G3、耳機主機板 Realtek）時，耳機自動改成各自對時，不會每隔一陣子「啵」一聲（耳機延遲約多 5 ms）。
- 響度會自動追蹤底噪：沒出聲時不會把雜音越拉越大。
- 伴奏卡卡：伴奏緩衝會自動跟著耳機裝置加大（耳機用主機板 Realtek 時特別需要）；進階設定的狀態會顯示伴奏緩衝和斷掉次數。
- 雜音：確認聲卡上的硬體監聽已關掉（不然耳機會同時聽到原音和處理後的聲音）。
- 錯誤紀錄：`%APPDATA%\PaPaVoiceFx\error.log`，把內容給 Claude。
